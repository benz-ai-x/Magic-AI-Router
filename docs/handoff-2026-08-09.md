## 关键决策（含理由，避免接手者反复）

### 1. AGF 全删，换 Matt Pocock 轻量 skills
AGF（AppGenesisForge）是 8.2 万行的多 agent 团队框架，对一个单人 macOS 菜单栏 app 过重。v0.4.0 曾删过又被 `17f7804` 重新引入；本会话彻底清除，用 Matt Pocock 的 issue-tracker/triage/domain-docs 约定替代（同样的 `docs/agents/` 结构，但无框架包袱）。

### 2. 严格路由：实现后又移除 ⚠️
严格路由（`strict_routing`）会禁用客户端内联覆盖（P1）+ SUBAGENT-MODEL（P2）。**用户实际用法是 Claude Code 经 env 注入 `provider/model` 内联覆盖直接选后端**——与严格路由冲突。故移除。**接手者不要再重新提议加严格路由**，除非威胁模型变化（网关暴露到网络/多人共用）。恢复路径：`git revert 545bc99`。

> 当前路由链（默认，无 strict）：内联覆盖 → SUBAGENT-MODEL → 自定义路由 → 长上下文 → 后台 → 规则 → 推理 → 默认。客户端覆盖始终被尊重。

### 3. 架构评审的 3 个「驳回」候选（勿重提）
- `ai_capture_addon.py` 6 个 reassemble 函数——`_STREAM_REASSEMBLERS` 策略表已存在，各家 SSE 格式本质不同，不值得统一。
- `suanpan/admin.py install_admin`——地道 FastAPI 路由注册，非 god-function。
- `_on_tick` converge-on-tick——抓包（CaptureController）和 SSH stderr（line_sink）移走后已清爽，剩余内联太薄。
