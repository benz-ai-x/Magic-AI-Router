# Magic Proxy icon assets

- `MagicProxy-v2.png`: production 1024 px app-icon source with transparency.
- `MagicProxy-v2.icns`: macOS application icon bundle.
- `MagicProxy-v2-chroma.png`: original generated artwork before background removal.

The v2 concept represents an SSH/network tunnel with bidirectional proxy traffic.
`build.sh` uses the v2 icon as the production application icon.
